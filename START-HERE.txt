==========================================================
  Stock-Agent — 더블클릭할 것은 셋뿐입니다
==========================================================

  RUN_ALL.cmd         ★ 이것 하나면 끝납니다.
                      환경 점검 → API 진단 → 원장 → 에이전트 → 리포트
                      다 하고 회의 자료 HTML 을 열어 줍니다.

                      중간에 죽어도 다시 돌리면 이어서 갑니다.
                      원장이 이미 있으면 40분짜리 적재를 다시 안 합니다.

                      RUN_ALL.cmd demo   에이전트를 가짜 응답으로 (무료)
                      RUN_ALL.cmd noai   숫자 리포트만
                      RUN_ALL.cmd auto   묻지 않고 끝까지

  SCHEDULE.cmd        매주 자동으로 돌리고 싶을 때. 등록·해제·상태를
                      한 창에서 고르시면 됩니다.
                      → 07:30  논문 수확 + 문헌 심사 (평일, 대개 몇 초)
                      → 08:50  아침 리포트 (평일 매일, 비용 없음)
                      → 16:10  장 마감 시세 적재 (평일 매일)
                      →        금요일엔 이어서 에이전트 분석 (~1시간)
                      → 등록되는 것도 결국 RUN_ALL.cmd 입니다.
                      → 기록은 logs 폴더에 남습니다.

                      ※ RUN_ALL 을 한 번 끝낸 뒤에 등록하십시오.
                        원장이 있어야 아침 리포트가 나옵니다.
                      ※ 금요일엔 컴퓨터를 17:30 까지 켜 두십시오.
                      ※ 폴더를 옮기셔도 됩니다. RUN_ALL 이 다음에 돌 때
                        어긋난 경로를 알아서 다시 등록합니다.

                      월요일 회의 자료는 금요일 밤에 완성됩니다.
                      월요일 아침엔 리포트로 찍어 내기만 합니다.

  PIXEL_FLOOR.cmd     에이전트가 도는 화면을 구경하고 싶을 때. (선택)
                      → 브라우저가 열립니다. SKHYNIX 나 BTC 를 넣어 보십시오.
                      → 필요한 것: Node (nodejs.org 에서 LTS)
                      → claude CLI 가 없으면 주소 끝에 ?demo=1 을 붙이십시오.
                      → 회의 자료에는 필요 없습니다. RUN_ALL 이 다 합니다.

----------------------------------------------------------
  나머지 폴더는 열어 보지 않으셔도 됩니다.

    stock-monitor\   사실을 재는 쪽 (파이썬). 원장과 리포트가 여기.
    trading-floor\   판단하는 쪽 (Node). 에이전트 17명이 여기.
    docs\            자세한 안내서. 막혔을 때만 보시면 됩니다.
                     RUN.md       처음부터 끝까지 손으로 하는 법
                     NETWORK.md   사내 방화벽에 막혔을 때 전산팀에 줄 요청서
----------------------------------------------------------
  막히면 화면에 나온 글자를 그대로 알려 주십시오.

  API 가 안 되면 먼저 이것을 돌려 보십시오:
      cd stock-monitor
      python ki_monitor.py diagnose

  "나가는 연결이 전부 막혀 있습니다" 가 나오면 사내 방화벽입니다.
  키 문제가 아닙니다. docs\NETWORK.md 를 전산팀에 그대로 넘기십시오.
----------------------------------------------------------

  주의 — 이 폴더에는 실제 API 키와 포트폴리오사 명단이 들어 있습니다.

        stock-monitor\watchlist.csv
