==========================================================
  Stock-Agent — 이 순서대로 더블클릭만 하시면 됩니다
==========================================================

  1_RUN_AGENTS.cmd    에이전트 화면을 켭니다
                      → 브라우저가 열립니다. SKHYNIX 나 BTC 를 넣어 보십시오.
                      → 필요한 것: Node (nodejs.org 에서 LTS)
                      → claude CLI 가 없으면 주소 끝에 ?demo=1 을 붙이십시오.

  ---- 여기까지가 "에이전트가 도는 것"을 보는 단계입니다 ----
  ---- 아래는 포트폴리오사(이노스페이스·카나프 등)를 붙이는 단계입니다 ----

  2_SETUP_LEDGER.cmd  원장을 만듭니다. 최초 1회, 약 40분.
                      → 필요한 것: Python (python.org, Add to PATH 켜기)
                      → API 키는 stock-monitor\.env 에 이미 넣어 두었습니다.

  3_ANALYZE.cmd       에이전트 16명이 포트폴리오사를 분석합니다.
                      → 종목당 수 분. 먼저 [1] 데모로 배선만 봐도 됩니다.

  4_REPORT.cmd        회의 자료 HTML 을 만들어 엽니다.

  ---- 매일 자동으로 돌리고 싶다면 ----

  INSTALL_SCHEDULE.cmd   평일 자동 실행을 등록합니다.
                      → 08:50  아침 리포트 (평일 매일, 비용 없음)
                      → 16:10  장 마감 시세 적재 (평일 매일)
                      →        금요일엔 이어서 에이전트 분석 (~1시간)
                      → 기록은 logs 폴더에 남습니다.
                      → 해제는 REMOVE_SCHEDULE.cmd
                      ※ 2번(원장)을 끝낸 뒤에 등록하십시오.
                      ※ 금요일엔 컴퓨터를 17:30 까지 켜 두십시오.

                      월요일 회의 자료는 금요일 밤에 완성됩니다.
                      월요일 아침엔 리포트로 찍어 내기만 합니다.
