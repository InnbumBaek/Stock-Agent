# 주가 모니터링

상장 포트폴리오사의 **회수(엑싯) 시점 판단**에 필요한 사실을 매일 자동으로 모아
단일 HTML 리포트로 만드는 도구입니다.

판단은 하지 않습니다. **측정값과, 그 측정값이 무엇을 셌는지, 어떤 가정 위에 서 있는지**만 냅니다.

---

## 무엇을 하는가

```bash
python ki_monitor.py daily
```

이 한 줄로 적재 → 매크로 수집 → 리포트 생성이 끝납니다.

리포트는 외부 리소스 0개인 **단일 HTML 파일**입니다. CDN을 부르지 않으므로
사내망이나 오프라인에서도 그대로 열립니다. 차트(SVG)도 라이브러리 없이 직접 그립니다.

### 리포트 구성 — 의사결정 순서

| § | 질문 |
|---|---|
| 1 | 무엇을 결정해야 하는가 — 회수계획 대비 진척 |
| 2 | 팔 수 있는가 — 처분 여건 |
| 3 | 어떻게 팔 것인가 — 실행 시뮬레이션 |
| 4 | 지금이 그 때인가 — 시장 환경 |
| 5 | 종목별 상세 |
| 6 | 밸류에이션 · 동종 비교 |
| 7 | 시장 배경 |
| 8 | 데이터 출처 · 한계 |

---

## 데이터 출처

크롤링하지 않습니다. 전부 공식 API입니다.

| 층 | 출처 | 인증 |
|---|---|---|
| 시세·지수·국고채·선물 | 한국거래소 KRX Open API | 헤더 `AUTH_KEY` |
| 공시·재무 | 금융감독원 DART Open API | 쿼리 `crtfc_key` |
| 해외 매크로 (선택) | FRED (세인트루이스 연준) | 쿼리 `api_key` |

자세한 이용 조건은 [`SOURCES.md`](SOURCES.md) 를 보십시오.
제3자 저작물(Nasdaq·ICE·Cboe 계열)은 기본값에서 제외되어 있습니다.

---

## 핵심 계산

- **처분 소요일수** — 시가총액 대비 물량을 장내에서 파는 데 걸리는 영업일수.
  평균 거래량 기준과 **중앙값 기준**을 나란히 냅니다. 거래대금이 상위 며칠에
  몰리는 종목은 평균값이 낙관적이기 때문입니다.
- **실행 시뮬레이션** — 매도 규칙 4종(즉시·균등·유동성비례·유동성상위일)을
  과거 구간마다 반복해 실현단가를 비교합니다. 가격 충격은 제곱근 모형을 가정합니다.
- **시장 국면** — 수준이 아니라 **분위**로 봅니다. "국고채 3.8%"는 맥락 없이
  높다 낮다 할 수 없지만 "관측기간 91분위"는 말할 수 있습니다.
- **매물대** — 가격대별 거래대금 분포.
- **수정주가** — 무상증자와 전환사채 희석을 구분합니다. 주가 실측이 주식수
  비율을 뒷받침할 때만 보정하고, 아니면 '확인 필요'로 남깁니다.

---

## 설계 원칙

**1. 예외가 안 난다고 맞는 게 아닙니다.**
금융 데이터 코드는 조용히 틀립니다. 컬럼이 뒤바뀌어도, 단위가 천원이어도 계산은 돌아갑니다.
그래서 교차검산·항등식·방향성 테스트를 둡니다.

```bash
python ki_monitor.py selftest    # 64개
```

**2. 모른다는 것을 아는 게 낫습니다.**
F-Score 항목 하나가 비면 0으로 채우지 않고 `None` 을 냅니다.
표본이 부족하면 계산을 거부합니다. 추적 불가 항목은 지우지 않고 '확인 불가'로 표시합니다.

**3. 가정을 드러냅니다.**
처분 소요일수는 참여율 가정, 가격 충격은 제곱근 모형 가정입니다.
숫자만 내면 가정이 숨습니다. 리포트에 가정을 적고 민감도를 함께 냅니다.

**4. 판단은 사람이 합니다.**
등급·점수·권고를 내지 않습니다.

## 시작하기

```bash
# 1) 키 설정
cp .env.example .env        # 그리고 값을 채웁니다
python ki_monitor.py check-auth

# 2) 감시 대상 지정
cp watchlist.sample.csv watchlist.csv
cp exit_plan.sample.csv exit_plan.csv

# 3) 과거 데이터 적재 (1년치, 약 30분)
python ki_monitor.py ingest --from 20250101 --universe KOSDAQ
python ki_monitor.py fundamentals --market KOSDAQ

# 4) 리포트
python ki_monitor.py report
```

### 필요 패키지

```
pandas numpy scipy requests lxml
```

`weasyprint` 가 있으면 PDF도 만듭니다. 없으면 HTML만 생성합니다.

## 명령

| 명령 | 설명 |
|---|---|
| `daily` | 적재 → 리포트 (자동화용) |
| `ingest` | KRX 일별 시세·지수·매크로 적재 |
| `fundamentals` | DART 주요계정 적재 |
| `macro-us` | FRED 해외 매크로 (선택) |
| `report` | 리포트 생성 |
| `eod` | 종가 기준 알림 평가 |
| `selftest` | 자체 검증 64개 |
| `check-auth` | 키 로딩 확인 (값은 출력하지 않음) |

## 저장소에 포함되지 않는 것

아래는 `.gitignore` 로 제외됩니다.

- `.env` — API 키
- `watchlist.csv`, `exit_plan.csv`, `positions.csv` — 실제 감시 대상 (대외비)
- `ki.sqlite` — 원장 (API로 재생성 가능)
- `out/` — 생성된 리포트

**생성되는 리포트는 대외비 문서입니다.** 상단에 배포 통제 배너가 찍히며,
외부 공유 전에 사내 승인이 필요합니다.
