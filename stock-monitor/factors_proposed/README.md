# 제안 팩터 — 관문을 통과해야만 실립니다

여기 있는 `.py` 파일은 **퀀트 데스크가 논문을 읽고 쓴 계산 코드**입니다.
`node server/paper-scan.js --years 2013-2026 --run` 이 여기에 넣습니다.

언어모델이 쓴 코드이므로 믿지 않습니다. 대신 **네 관문**을 통과해야만 돌립니다.

| 관문 | 무엇을 막는가 |
|---|---|
| 정적 | `import`·`eval`·`exec`·`open`·던더 접근·바깥에서 끌어오는 이름. 파일도 네트워크도 못 건드립니다 |
| 계약 | `compute(df, mkt, list_date, win)` 이고 `(값, 관측수, 사유)` 3-튜플을 내는가 |
| 연기 | 합성 원장으로 실제로 돌려 예외·무한대·NaN 이 없는가 |
| **검산** | **META 의 `check.expect` 와 실제 계산이 맞는가** |
| 인용 | `paper` 가 `.papers.json` 의 채택본에 실재하는가 |

검산 관문이 핵심입니다. 알려진 계열(하루 `rate` 씩 오르는 300일)에서 나올 값을
**손으로 계산해 적지 못하면 싣지 않습니다.** 검산되지 않은 계산이 회의 자료에
실리는 것이 이 시스템이 막으려는 실패입니다.

통과해도 **채택본과 섞이지 않습니다.** `ki.factors/1` 의 `proposed` 목록으로
따로 나가고, 값마다 "제안 — 검산 통과 · 사람이 채택하기 전" 딱지가 붙습니다.

## 채택하려면

1. 원문을 확인하십시오.
2. `.papers.json` 에 논문을 채택본으로 옮기고 `question`·`claim`·`limits` 를 적으십시오.
3. `ki_monitor.py` 의 `FACTOR_DEFS` 로 옮기고, `selftest` 에 손으로 낸 검산을 추가하십시오.
4. 그러고 나서 이 폴더의 파일을 지우십시오.

## 형식

```python
# META: {"name":"이름","unit":"%","paper":"채택본_논문키","question":"q1",
#        "claim":"논문이 주장한 것","limits":"주장하지 않는 것",
#        "check":{"rate":0.002,"n":300,"win":60,"expect":23.0957,"tol":0.001}}
def compute(df, mkt, list_date, win):
    ...
    return 값, 관측수, 사유_또는_None
```

쓸 수 있는 것은 `df` · `mkt` · `list_date` · `win` · `pd` · `np` · `math` 와
지역변수뿐입니다. 값이 없으면 `(None, n, 사유)` 를 돌려주십시오 — 0 으로 채우면 안 됩니다.
