# 데이터 출처 및 이용 조건

이 도구가 사용하는 모든 외부 데이터의 출처와 저작권 주체입니다.

> 이 문서는 법률 자문이 아닙니다. 조직에서 업무 목적으로 사용하시려면
> 각 제공처의 이용약관을 직접 확인하십시오.

---

## 1. 사용하는 출처

| 출처 | 데이터 | 저작권 주체 | 인증 |
|---|---|---|---|
| KRX 정보데이터시스템 Open API | 종목 일별시세, 지수, 국고채, 채권지수, 선물 | 한국거래소 | 인증키 (서비스별 사용신청) |
| DART Open API | 공시목록, 기업개황, 주요계정 재무 | 금융감독원 | 인증키 |
| FRED (공공 계열만) | 미국 국채 2년·10년, 장단기 스프레드, 달러지수 | Federal Reserve Board (미국 정부 저작물) | 무료 API 키 |

KRX는 인증키 발급과 별개로 **서비스별 URL 사용신청**이 필요합니다.
신청하지 않은 서비스는 키가 유효해도 401을 돌려줍니다.

## 2. 의도적으로 제외한 것

아래는 FRED로 받아볼 수는 있으나 **저작권이 제3자에게 있어 기본값에서 제외**했습니다.
`macro-us --include-restricted` 로만 켜지며, 켜기 전에 해당 제공처의 조건을 확인하십시오.

| 계열 | FRED 코드 | 저작권 주체 |
|---|---|---|
| VIX | `VIXCLS` | Cboe Exchange, Inc. |
| 나스닥 종합지수 | `NASDAQCOM` | Nasdaq, Inc. |
| 미국 하이일드 스프레드 | `BAMLH0A0HYM2` | ICE Data Indices, LLC |

이미 적재된 제3자 계열은 `macro-us --purge-restricted` 로 원장에서 지울 수 있습니다.

## 3. 사용하지 않는 것

- **웹 크롤링 없음.** 어떤 사이트도 스크래핑하지 않습니다. 전부 공식 API입니다.
- **유료 벤더 데이터 없음.** 애널리스트 컨센서스·목표주가 미사용.
- **뉴스 기사 없음.** 언론사 콘텐츠를 복제하지 않습니다.
  기업 관련 사건은 DART 공시 원문으로만 표시합니다.

## 4. 생성물에 자동으로 표기되는 내용

- 출처 3곳 명기 (§ 데이터 출처)
- 제3자 저작 계열을 켠 경우 그 저작권 주체
- 투자권유·투자자문 자료가 아니라는 고지
- 배포 통제 배너 (`STAGE` 설정에 따름)

## 5. 배포 통제 스위치

`ki_monitor.py` 의 `STAGE` 값으로 제어합니다.

- `personal` (기본) — 워터마크 표시, 알림 발송 안 함
- `corporate` — `ENV["corporate"]["recipients"]` 에 수신자 기재

생성되는 리포트에는 감시 대상 기업의 실명과 처분 관련 지표가 포함됩니다.
조직에서 사용하실 경우 **데이터 라이선스보다 열람 범위 관리가 실질적으로 더 중요합니다.**
